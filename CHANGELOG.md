# Changelog

All notable changes to In-Summary are documented in this file. This project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) and
records release evidence per slice under `openspec/archive/`.

## [1.0.0] — 2026-09-14

Phase 2 of v1 of In-Summary. First release with the local PDF reader and the
per-page PencilKit ink overlay on iPad. iPad-only, local-only, fully offline.
No iCloud, CloudKit, network, import, export, or sync code path ships in v1.

### Added

- **`pdf-fixture` — bundled deterministic PDF**
  - `InSummary/Resources/Fixtures/sample-bundle.pdf` — project-authored,
    deterministic, CC0-licensed, 20-page sample PDF at exactly the canonical
    path. Regenerated by `Tools/generate-sample-bundle-pdf.swift` whenever
    the generator source changes.
  - `InSummary/Resources/Fixtures/SAMPLE-BUNDLE-LICENSE.md` — CC0 dedication,
    generator SHA-256, page count.

- **`pdf-engine` — local reader coordinator**
  - `InSummary/Services/PDFEngine/PDFReaderCoordinator.swift` — `@MainActor`
    `UIViewRepresentable` that owns a `PDFView`. Reads
    `DocumentItem.paginationModeRaw` once on open and writes it back on
    toggle; does not add, alter, or migrate the field.
  - `InSummary/Services/PDFEngine/PDFReaderError.swift` — typed errors
    (`fixtureMissing`, `fixtureUnreadable`, `unsupportedDocument`,
    `paginationSaveFailed`).

- **`pencilkit-ink-overlay` — page-anchored handwriting**
  - `InSummary/Services/AnnotationEngine/PencilCanvasOverlay.swift` —
    `UIViewRepresentable` wrapping `PKCanvasView` with
    `drawingPolicy = .pencilOnly`, highlighter as the default tool, and
    direct read/write of `PageAnnotation.drawingData` (no parallel file
    store).
  - `InSummary/Services/AnnotationEngine/PDFPageChangeObserver.swift` —
    `@MainActor final class` that swaps `PKDrawing` payloads across pages
    and value-coalesces on `currentPageIndex`.
  - `InSummary/Services/AnnotationEngine/AnnotationError.swift` — typed
    errors (`drawingDecodeFailed`, `drawingPersistenceFailed`).

- **`pdf-reader-wiring` — SwiftUI reader surface**
  - `InSummary/Views/Reader/ReaderContainerView.swift` — composes the
    coordinator and the overlay, subscribes the page-change observer to
    the coordinator's publisher, surfaces recoverable error banners.
  - `InSummary/Views/Reader/PDFViewRepresentable.swift` — thin
    `UIViewRepresentable` over `PDFView` so the coordinator can read the
    live reference.
  - `InSummary/Views/Library/LibraryGridView.swift` — seed PDF row becomes
    a `NavigationLink` to `ReaderContainerView(document:)`; non-PDF or
    non-seed rows surface a recoverable "not supported in this build"
    alert.

### Phase 1 baseline (byte-for-byte preserved, reused as v1 invariants)

- `InSummary/Models/DocumentItem.swift` — `paginationModeRaw: String`
  default `"horizontal"`. Phase 2 reads it on open and writes it on toggle.
- `InSummary/Models/PageAnnotation.swift` — `drawingData: Data?` declared
  with `@Attribute(.externalStorage)`. Phase 2 reuses it as the per-page
  ink store.
- `InSummary/Services/Persistence/` — schema, `ModelContainer`, and
  `LibrarySeedService` unchanged.
- `InSummary/Info.plist` — no new usage descriptions; PDF access is
  bundle-only in v1.

### Test evidence

- 39 new XCTest cases added across the four Phase 2 slices
  (14 + 11 + 12 + 2). Phase 1 baseline (56 tests) is byte-for-byte
  unchanged.
- Full XCTest suite on the iPad Pro 13-inch (M5), iOS 26.5 simulator:
  **95/95 green**, captured in
  `openspec/archive/pdf-reader-pencilkit-ink-recovery/archive.md` §3.1.
- Blocked-substring grep guard (no iCloud / CloudKit / network / import
  / export / sync in product code) — zero matches across
  `InSummary/Services/PDFEngine/`, `InSummary/Services/AnnotationEngine/`,
  and `InSummary/Views/Reader/`.
- Airplane-mode acceptance — passed by construction; the suite is
  timing-independent and uses no remote-capability call site.

### Stack and platforms

- Target: iPad only (`TARGETED_DEVICE_FAMILY = 2`). No iPhone, no Mac
  Catalyst, no visionOS.
- First-party frameworks only: `Foundation`, `SwiftData`, `PDFKit`,
  `PencilKit`, `SwiftUI`, `UIKit`, `os`. No third-party SDKs.
- Swift 6.0, iOS deployment target 26.0.
- Signing: personal / development. No Apple Developer Program
  capabilities (push, CloudKit container, App Group across devices) are
  exercised.

### Non-goals (explicit, deferred out of v1.0.0)

- PDF import via `.fileImporter`, `UIDocumentPickerViewController`, or
  `PHPickerViewController` — Phase 5.
- Library, folders, drag-and-drop organization — Phase 5.
- Burned-in PDF export — Phase 5.
- Sticky notes — Phase 4.
- Semantic highlights (PDF text selection) — Phase 4.
- Markdown or EPUB engines — Phase 3.
- iCloud / CloudKit sync, "Make available on my other devices", `CKAsset`,
  push notifications, background URL sessions — future phase; the
  blocklist in `openspec/config.yaml` enforces this in product code.
